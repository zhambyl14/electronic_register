## 1. Зерттеу: iMag Kassa-да шынымен не бар

Таза логиканы Python-ға жолма-жол көшіріп, нақты сандармен тексердім: `verification/verify_logic.py`, **15/15 тест өтті**. Flutter бұл ортада орнатылмаған, сондықтан қосымшаның өзі іске қосылған жоқ. ### ⚠️ Тексеру кезінде табылған нәрселер (видеоларға қосылмады)
1. **Таразының COM-портын таңдайтын экран жоқ.** `SETUP.md` «Баптаулар → Таразы» дейді, бірақ `settings_screen.dart` ішінде мұндай бөлім жоқ. Қосымша тек `%LOCALAPPDATA%\MagKassa\settings.json` ішіндегі `scalePort` мәнін оқиды, ал оны жазатын код жоқ. Видео 01 мен 02-де таразы көрсетілген, сондықтан жарияламас бұрын осы баптау қолмен жасалғанын тексеріңіз немесе экранын қосыңыз.
2. **VFD-дегі «РАХМЕТ! Сдача…» жазуы ешқашан шықпайды:** `showPaymentComplete()` еш жерде шақырылмайды. Видео 06-да тек нақты жұмыс істейтін нәрсе көрсетілді: тауарлар саны мен ИТОГО.
3. **Салмақ штрих-кодында сома 5 цифр (тиынмен) болады**, яғни бір этикеткада ең көбі **999.99 ₸**. Видео 03-тің мысалы осы шекке сыяды (709.50 ₸). Бұдан қымбат тауарға таразыны басқа форматқа баптау керек.
4. **БИН** чекке басылады, бірақ профильде сақталмайды, сондықтан қайта іске қосқанда жоғалады. Видеоларда БИН көрсетілмеді.
5. **Телефоннан қарау** арнайы мобильді қосымша арқылы емес. Деректер бұлтта, Firebase web-конфигурациясы бар, яғни сол логинмен басқа құрылғыдан кіргенде есептер көрінеді. Ағаның оқиғасы (видео 01) осыған негізделген. Ағай қай жолмен кіретінін (браузер ме, басқа нұсқа ма) өзіңіз нақтылап алыңыз.
6. Бұл **фискалдық касса емес** (ОФД/салық жүйесімен байланысы жоқ). Сондықтан видеоларда «фискал» сөзі мүлдем қолданылмады.

## 2. Дауыс (диктор)

**Ең жақсы тегін вариант: Microsoft Neural TTS** (`kk-KZ-DauletNeural` — ер дауыс, `kk-KZ-AigulNeural` — әйел дауыс). Қазақ тіліне арнайы үйретілген, таза әрі табиғи естіледі, API кілт керек емес.
Бұл бұлттық ортадан Microsoft сервері жабық болғандықтан, дауысты видеоға **өз компьютеріңізде бір командамен** қосасыз:

```
pip install edge-tts
python make_voice.py            # барлық видео → out/NN/iMag_NN_voice.mp4
python make_voice.py 01 --rate +12%
```
Скрипт әр сөйлемді өз уақытына қояды. Сөйлем ұзын болса, оны 15%-ға дейін жылдамдатады, ал дауыс шыққан кезде музыканы автоматты түрде бәсеңдетеді. Брендтің оқылуы `SAY` сөздігінде берілген («iMag» → «Ай Маг»), қаласаңыз өзгерте аласыз.
Нағыз диктормен жазғыңыз келсе, төмендегі «Диктор» бағанындағы мәтінді сол күйінде оқытыңыз: уақыттары кестеде көрсетілген.

**Музыка мен эффектілер** кодпен нөлден синтезделген (`audio/synth.py`). Ешқандай сэмпл не дайын трек қолданылмады, сондықтан авторлық құқық мәселесі жоқ.
